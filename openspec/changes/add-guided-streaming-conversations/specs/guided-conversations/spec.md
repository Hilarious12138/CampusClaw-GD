## ADDED Requirements

### Requirement: Bearer 身份与资源边界
系统 MUST 复用 Bearer JWT，并从数据库查询角色和成员班级；智能体、技能与材料以班级隔离，会话再以创建者隔离。

#### Scenario: 越权与不存在相同
- **WHEN** 无有效令牌、学生写教师配置，或同班他人/外班用户直取资源
- **THEN** 分别返回 401、403、404；外班/他人与不存在资源的 404 正文一致，客户端伪造班级/角色/历史无效

### Requirement: 教师配置多个智能体
系统 SHALL 允许教师创建与更新本班智能体的名称、角色提示词、启用状态以及本班技能/材料绑定；初始班级至少有数学和语文助手。

#### Scenario: 配置和停用
- **WHEN** 教师保存合法配置并重启，或停用一个已有会话使用的智能体
- **THEN** 数据库保存配置且重启不覆盖；学生列表隐藏停用项、新建被拒绝，但旧会话仍可继续

#### Scenario: 非法绑定
- **WHEN** 教师提交他班技能/材料、重复名称或超过字段上限
- **THEN** 返回 404 或 400，不写入部分关联记录

### Requirement: 技能源文本与确定性路由
系统 SHALL 保存技能名称、适用条件、可选资料主题、启用与说明；每轮只从智能体绑定且启用的技能中选择最多一条。

#### Scenario: 命中与并列
- **WHEN** 问题包含多个逗号/顿号/分号/竖线分隔的触发词
- **THEN** 命中词数最多者入选，同分取最小 ID；没有命中则不选技能，停用/解绑后下一轮即时生效

#### Scenario: 解题引导
- **WHEN** 入选技能的名称包含“解题引导”
- **THEN** 系统约束要求只提示思路和下一步，不直接提供最终答案、选项或完整解法；未入选的此类技能不施加该约束

### Requirement: 个人会话与有效历史
系统 SHALL 让学生和教师选启用智能体创建个人会话，创建后的 agent_id 不变；历史只由服务端读取最近六条有效消息，每条最多 500 字。

#### Scenario: 创建与继续
- **WHEN** 用户新建会话、发送首问后重新登录，或教师修改角色提示词
- **THEN** 会话标题为首问前 24 字，消息与快照持久化；后续轮次使用新配置，失败草稿不进入生成历史

#### Scenario: 并发和断连
- **WHEN** 同一会话同时发送、模型失败或客户端取消
- **THEN** 并发请求 409，不新增重复轮次；故障记 failed/cancelled 草稿，详情可恢复，不假报 completed

### Requirement: 限定绑定材料的本班检索与引用
系统 MUST 每轮先以最新问题 hybrid 检索智能体绑定的本班材料，前四片再过滤空正文与不符所选技能主题的材料标题；正文与出处从 MySQL 回取。

#### Scenario: 可追溯出处
- **WHEN** 有有效切片
- **THEN** meta 先于模型文字提供材料标题、切片序号、字符区间、摘录和鉴权打开入口；Qdrant 向量标识不能替代正文或绕过 MySQL 权限检查

#### Scenario: 无依据仍回答
- **WHEN** 绑定材料中没有候选或过滤后为空
- **THEN** 仍调用对话模型，meta.status 为 ok、citations=[]；流式答案中的伪引用编号被清除，不显示编造的出处

#### Scenario: 第四课保留
- **WHEN** 调用既有 /api/retrieval/search 或 /api/ask
- **THEN** 三种检索模式和单次问答的无依据固定提示保持原契约

### Requirement: Bearer POST 真流式输出
系统 SHALL 从上游 stream=true 增量转发 SSE，不把完整回答切字模拟流式。

#### Scenario: 事件与持久化
- **WHEN** 模型逐片返回合法内容
- **THEN** 依次发 meta、至少一次 delta、数据库写完后发一次 done；拼接 delta 等于保存正文，meta 引用来自本轮真实证据，正文若出现编号则仅指向这批证据

#### Scenario: 流后失败
- **WHEN** 已发 meta 后发生坏帧、越界引用、数据库失败、过期或取消
- **THEN** 发 error 或断连并保留非完成状态，不再发 done；流前参数/鉴权失败仍用 JSON HTTP 错误

### Requirement: 可试调 Swagger 与接口验收
系统 MUST 提供描述实际路径、入参出参、错误和认证的 /openapi.json、/swagger/，并提供按 URL/METHOD 分脚本的 apitest 一键 HTML 报告。

#### Scenario: 文档试调
- **WHEN** 浏览器打开 Swagger 并用登录得到的 Bearer 调用主要接口
- **THEN** 公共路由无需认证，受保护路由携带令牌；Swagger 不持久化令牌，SSE 契约可见

#### Scenario: 报告与数据库断言
- **WHEN** 运行 run_all.py 或单个接口脚本
- **THEN** 登录、检索、配置、会话和消息同时校验响应、权限及 MySQL 行；失败退出非零，报告不入 Git 且不含密码、令牌或模型密钥
